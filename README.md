# Project NOEMA

> We did not merely train an LLM to abstain.  
> We trained it to preserve an unresolved state, identify exactly what remains unresolved, and infer the evidence required to resolve it.

Project NOEMA is an independent research program on epistemic-state control, unresolved-state preservation, evidence targeting, and cognitive execution in large language models.

The research has progressed from explicit serialized reasoning procedures toward latent modular cognitive execution.

## Research Lineage

**NOEMA-1 → NOEMA-Organ → NOEMA-OrganFarm**

- **NOEMA-1**  
  Procedure-oriented post-training for epistemic-state control using structured serialized intermediate representations.

- **NOEMA-Organ**  
  Experimental transition from externally generated cognitive procedures toward trainable latent functional modules inserted into a largely frozen language model.

- **NOEMA-OrganFarm**  
  A modular latent cognitive architecture in which separately trained functional “Organs” operate through Functional Freeze, latent-state inheritance, deterministic routing, and state-dependent conditional execution.
