# Project NOEMA

> We did not merely train an LLM to abstain.  
> We trained it to preserve an unresolved state, identify exactly what remains unresolved, and infer the evidence required to resolve it.

This repository contains research materials related to Project NOEMA.

The primary paper describing the reported method and experimental results was publicly released on Zenodo on September 16, 2026.
